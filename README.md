SkillUp - Responsive Landing Page

Project Description

SkillUp is a responsive educational landing page designed to help learners explore courses and develop new skills.

Internship Task

SDM Technology Internship - Week 2: Responsive Layout Project.

Technologies Used

- HTML5
- CSS3
- JavaScript

Features

- Responsive navigation menu
- Attractive hero section
- Course cards
- Web Development, Python and AI learning sections
- About section
- Contact section
- Responsive footer
- Mobile-friendly layout

Layout Techniques

- CSS Flexbox for navigation, buttons, footer and content alignment.
- CSS Grid for the hero section and course cards.
- Media queries for mobile and tablet responsiveness.

Responsive Testing

The website is designed and tested at:

- Mobile: 360px
- Tablet: 768px
- Desktop: 1280px

Project Files

- index.html - Website structure
- style.css - Styling and responsive layout
- script.js - Navigation menu and footer year
- Output - Screenshots of the project

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Explore the website.

Output

The project provides a responsive educational landing page that works across mobile, tablet and desktop screens.
